# E2E TESTING CHECKLIST - CAREER TRACKER APP

================================================================================
1. AUTHENTICATION & SECURITY
================================================================================
[ ] Login Mahasiswa (Success & Invalid Credentials)
[ ] Login Dosen (Success & Invalid Credentials)
[ ] Login Staff (Success & Invalid Credentials)
[ ] Registrasi Mahasiswa Baru
[ ] Registrasi Pegawai (Dosen/Staff)
[ ] Lupa Password (Request Reset Link via Email)
[ ] Reset Password (Update via Token)
[ ] Ubah Password (di dalam Dashboard)
[ ] Logout & Session Clearing

================================================================================
2. MAHASISWA FLOW (END-TO-END)
================================================================================
[ ] Dashboard: Menampilkan ringkasan status pendaftaran
[ ] Lowongan: Mencari & melihat detail lowongan magang
[ ] Pendaftaran: Mengunggah CV & Surat Rekomendasi (Daftar Magang)
[ ] Riwayat: Memantau status lamaran (Pending -> Accepted/Rejected)
[ ] Logbook: Menambah entry harian (Jenis kegiatan, Keterangan, Media)
[ ] Logbook: Mengunggah foto dokumentasi kegiatan
[ ] Logbook: Mengedit & menghapus entry lama
[ ] Laporan Akhir: Mengunggah dokumen laporan (.pdf)
[ ] Profil: Memperbarui data Nama, NIM, Fakultas, & Prodi

================================================================================
3. DOSEN FLOW (END-TO-END)
================================================================================
[ ] Dashboard: Menampilkan daftar mahasiswa bimbingan aktif
[ ] Tinjau Progres: Melihat daftar logbook mahasiswa secara real-time
[ ] Tinjau Progres: Pratinjau/Unduh dokumen laporan akhir mahasiswa
[ ] Penilaian: Memberikan nilai angka (0-100) & Status Kelulusan
[ ] Penilaian: Memberikan catatan revisi/feedback
[ ] Rekomendasi: Mengunggah surat rekomendasi untuk mahasiswa
[ ] Profil: Memperbarui data Nama & NIP

================================================================================
4. STAFF FLOW (END-TO-END)
================================================================================
[ ] Lowongan: Menambah lowongan baru (Judul, Perusahaan, Deskripsi, Kuota)
[ ] Lowongan: Mengedit detail lowongan & menghapus lowongan
[ ] Verifikasi: Melihat antrean pendaftaran mahasiswa (Status PENDING)
[ ] Verifikasi: Pratinjau inline dokumen CV & Rekomendasi Mahasiswa
[ ] Verifikasi: Mengubah status menjadi ACCEPTED (Cek trigger inisialisasi laporan)
[ ] Verifikasi: Mengubah status menjadi REJECTED
[ ] Profil: Memperbarui data Nama & NIP

================================================================================
5. SYSTEM INTEGRATION (CROSS-CUTTING)
================================================================================
[ ] Notifikasi: Muncul saat ada update status pendaftaran (Mahasiswa)
[ ] Notifikasi: Muncul saat ada pendaftar baru (Staff)
[ ] Notifikasi: Muncul saat mahasiswa upload laporan (Dosen)
[ ] Notifikasi: Fitur "Tandai Semua Dibaca" berfungsi (Backend & UI)
[ ] Proteksi Rute: User tidak bisa akses halaman role lain via URL
[ ] Interceptor: Token kedaluwarsa otomatis redirect ke login (401)
